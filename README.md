# Showdown for iPhone

A native SwiftUI client for [Pokémon Showdown](https://pokemonshowdown.com). It connects to the real Showdown servers, so you battle the same players and ladders as on the website.

- **Battles:** animated sprites, HP bars, weather effects, haptics, Terastallization, doubles targeting, team preview, battle log and chat
- **Matchmaking:** every ladder format, challenges to and from friends, and reconnect-and-rejoin if the app drops
- **Teambuilder:** paste a Showdown export or Pokepaste, or build sets visually with species, move and item search, EV sliders and live stat calculation
- **Accounts:** sign in with your registered Showdown name. The password stays in the iOS Keychain.

## Installing without the App Store

GitHub Actions builds an unsigned `Showdown.ipa` on every push. Find it under **Actions → Build → Artifacts**, or on the **Releases** page for tagged versions.

To install it on your iPhone, sign it with your own Apple ID using a sideloading tool:

1. Install [SideStore](https://sidestore.io) (or [AltStore](https://altstore.io)) on your iPhone, following its setup guide.
2. Download `Showdown.ipa` on the phone and open it with SideStore. SideStore signs it with your Apple ID and installs it.
3. A free Apple ID signature lasts 7 days, and SideStore refreshes it automatically. A paid developer account ($99/yr) lasts a year.

To publish a release: `git tag v1.0.0 && git push --tags`.

## Project layout

| Path | What it is |
| --- | --- |
| `ShowdownKit/` | Swift package with no UI: protocol parser, battle state engine, request and choice models, team import/export/packing, Pokédex models. Runs on Linux, and `swift test` covers it. |
| `App/` | The SwiftUI app: connection, login, battle playback and animation, screens |
| `project.yml` | [XcodeGen](https://github.com/yonaskolb/XcodeGen) spec. Run `xcodegen generate` to get `Showdown.xcodeproj`. |

The battle engine is tested against battles generated by the official `pokemon-showdown` simulator (`ShowdownKit/Tests/ShowdownKitTests/Fixtures`).

## Building locally (Mac)

```sh
brew install xcodegen
xcodegen generate
open Showdown.xcodeproj
```
